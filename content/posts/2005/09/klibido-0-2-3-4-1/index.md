Well, tonight a updated [klibido](https://klibido.sourceforge.net/) with the last bugs fix release from Bauno.

- Sarge user:
  Add this line in your /etc/apt/sources.list unless that's allready done.

  > deb http://orniere-du-globe.net/debian/ ./

- Sid use:
  Add this line:

  > deb http://orniere-du-globe.net/debian**-sid**/ ./

Then you've just to:

> apt-get update
> apt-get install klibido

Ubuntu users, you'll certainly have to rebuild the package. If you do the job, please can you submit a link with a fresh package in the comments.
